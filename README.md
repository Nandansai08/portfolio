- Intelligent group expense management with minimal transactions
- Uses **greedy graph algorithms** to minimize transfers (N×(N-1) → N-1)
- Features: JWT auth, equal/exact/percentage splits, recurring expenses
- **Stack:** Node.js, Express, MongoDB, Vanilla JS, HTML/CSS
- 🔗 [Live Demo](https://novasync.onrender.com) | [GitHub](https://github.com/Nandansai08/NovaSync)
